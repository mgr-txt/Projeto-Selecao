# Projeto de Seleção para o Projeto de Tecnologia

Programa desenvolvido em Python para realizar a seleção de candidatos para um projeto de tecnologia.

## Sobre o projeto

O programa coleta informações do candidato, verifica seus conhecimentos, disponibilidade e outras condições, calcula uma pontuação e apresenta sua classificação.

## Conceitos utilizados

- Variáveis
- `input()`
- Conversão de tipos
- Dicionários
- Tuplas
- Conjuntos (`set`)
- `intersection()`
- `difference()`
- Operadores relacionais e lógicos
- Estruturas condicionais (`if`, `elif`, `else`)
- Valores booleanos

## Regras de seleção

O candidato é considerado aprovado quando:

- Possui pelo menos 16 anos;
- Possui pelo menos 3 conhecimentos exigidos;
- Está disponível nos turnos da manhã ou tarde;
- Possui capacidade de trabalhar em equipe;
- Obtém pelo menos 7 pontos.

Com Python instalado, execute:
